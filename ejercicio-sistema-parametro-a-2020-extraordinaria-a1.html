Ejercicio A.1

Discusión y resolución completa

Teoría necesaria

1. Matriz ampliada y operaciones elementales

La matriz ampliada contiene los coeficientes de las incógnitas y la columna de términos independientes. Sumar a una fila un múltiplo de otra produce un sistema equivalente: cambia su escritura, pero no sus soluciones.

2. Forma escalonada y pivotes

En una matriz escalonada, cada fila no nula aporta un pivote. El número de pivotes es el rango. Si aparecen tres pivotes para tres incógnitas, el sistema tiene una única solución.

3. Teorema de Rouché-Frobenius

Un sistema es compatible cuando la matriz de coeficientes y la ampliada tienen el mismo rango. Si la ampliada tiene mayor rango, aparece una contradicción y no existe solución.
